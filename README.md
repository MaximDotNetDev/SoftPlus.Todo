# SoftPlus.Todo (To-Do App)

Репозиторій із тестовим завданням на позицію Trainee/Junior Full Stack Developer для компанії SoftPlus Ukraine.

Застосунок являє собою аналог Microsoft To-Do для керування щоденними завданнями та категоріями. Проєкт виконано відповідно до надісланих технічних вимог, із чітким розділенням на незалежний бекенд (REST API) та фронтенд (Angular SPA).

## 🛠 Технологічний стек

### Бекенд (Back-end)

* Платформа: .NET 10 (Web API)
* Доступ до даних: Entity Framework Core 10 (MS SQL Server LocalDB)
* Безпека: Аутентифікація на базі JWT-токенів (System.IdentityModel.Tokens.Jwt), хешування паролів за допомогою BCrypt.Net-Next.
* Документація: Специфікація OpenAPI (Microsoft.AspNetCore.OpenApi) + інтерактивний інтерфейс Scalar.AspNetCore для тестування ендпоінтів.

### Фронтенд (Front-end)

* Фреймворк: Angular 22 (Standalone-компоненти, робота зі станом через Signals та RxJS).
* Стилізація інтерфейсу: Tailwind CSS (адаптивний дизайн, кастомні компоненти).

## 🏛 Архітектура бекенду (4-х рівнева структура)

Код рознесено на 4 окремі проєкти (шари) всередині одного рішення для забезпечення чистоти, гнучкості та слабкої зв'язності (Loose Coupling):

1. `SoftPlus.Todo.Interfaces` — доменні моделі/сутності (User, TodoTask, Category, SubStep), DTO-контракти для запитів/відповідей та інтерфейси репозиторіїв.
2. `SoftPlus.Todo.DataAccess` — реалізація доступу до бази даних (MS SQL). Включає AppDbContext, налаштування зв'язків між таблицями (Fluent API), міграції та конкретні класи репозиторіїв.
3. `SoftPlus.Todo.Services` — шар бізнес-логіки. Обробка бізнес-правил, валідація, генерація JWT-токенів, шифрування паролів та мапінг сутностей у DTO.
4. `SoftPlus.Todo.Api` — контролери ASP.NET Core, конфігурація Dependency Injection (DI), обробка CORS-політики та підключення документації API.

## 💻 Функціонал застосунку

* Авторизація користувачів (Log in / Log out / Register): Повноцінна реєстрація та вхід. Доступ до завдань є приватним — кожен користувач бачить і редагує виключно свої дані (використовується вилучення UserId із JWT-токена на рівні бекенду).
* Керування завданнями: Створення, перегляд, редагування назви/опису, вибір дати виконання (DueDate) та видалення (CRUD).
* Підкроки (Substeps): Можливість додавати дрібні чек-лісти всередині конкретного завдання.
* Категорії: Створення та видалення категорій, прив'язка завдань до категорій для структурування списків.
* Пошук та фільтрація: Пошук завдань за текстом (з дебаунсом у 350 мс для оптимізації запитів до БД) та фільтрація списку за обраною категорією.
* Пагінація: Посторінковий вивід списку завдань для зменшення об'єму даних, що передаються мережею.
* Optimistic UI: Локальне оновлення інтерфейсу у фронтенді (наприклад, при зміні статусу завдання чи додаванні) відбувається миттєво, не чекаючи відповіді від сервера. Якщо сервер повертає помилку — стан коректно відкочується.

## 📦 Інструкція із запуску проєкту

### 1. Налаштування та запуск Бекенду

Переконайтеся, що у вас встановлено .NET 10 SDK та запущено MS SQL Server (або LocalDB).

1. Перейдіть у корінь проєкту бекенду:
   ```bash
   cd SoftPlus.Todo
   ```
   
2. Відновіть залежності:
    ```bash
    dotnet restore
    ```

3. Застосуйте міграції для створення бази даних TodoDb та її таблиць:
    ```bash
    dotnet ef database update --project SoftPlus.Todo.DataAccess --startup-project SoftPlus.Todo.Api
    ```

4. Запустіть API-сервер:
    ```bash
    dotnet run --project SoftPlus.Todo.Api
    ```

> Примітка: Після запуску документація API (Scalar UI) буде доступна за адресою: https://localhost:7289/scalar/v1

### 2. Налаштування та запуск Фронтенду

Переконайтеся, що у вас встановлено Node.js (v20+).

1. Перейдіть до папки з фронтенд-частиною:
    ```bash
    cd SoftPlus.Todo/softplus-todo-front
    ```

2. Встановіть необхідні npm-пакети:
    ```bash
    npm install
    ```

3. Запустіть локальний сервер розробки Angular:
    ```bash
    npm start
    ```

> Примітка: Відкрийте у браузері сторінку: http://localhost:4200
